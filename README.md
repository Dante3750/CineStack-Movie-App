# CineStack: Modern Movie Discovery & Library

[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen.svg)](https://developer.android.com/android)
[![Architecture](https://img.shields.io/badge/Architecture-MVVM--Clean-blue.svg)](https://developer.android.com/topic/architecture)

CineStack is a high-performance movie discovery application built to showcase modern Android development best practices. It features real-time search, offline bookmarking, and a modular architecture.

---

## 🚀 Key Technical Solutions
- **Offline-First Bookmarkinga**: Robust local persistence layer using **Room**.
- **Optimized Real-time Search**: Coroutine **Flow operators (Debounce)** for responsive experience.
- **Material 3 Design System**: Full implementation of M3 with dynamic color support.

## 🛞 Tech Stack
- Kotlin, Jetpack Compose (M3), Room, Retrofit, Dagger-Hilt, Coroutines & Flow.
